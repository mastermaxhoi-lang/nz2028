# Новая Зеландия, январь 2028

Статическая страница поездки: маршрут по дням, цены, как попасть в чат.
Исходник живёт в Life OS: `03-Личное/увлечения/путешествия/Новая-Зеландия/сайт/`,
сюда копируется для публикации на GitHub Pages.

- `index.html` — страница целиком, вся вёрстка внутри
- `img/` — фотографии, карта и QR
- `robots.txt` + `<meta name="robots" content="noindex">` — страница открыта по ссылке,
  но не попадает в поисковики: в ней инвайт-ссылка на чат поездки

## Обновить

```bash
cp -R "<Life OS>/03-Личное/увлечения/путешествия/Новая-Зеландия/сайт/." ~/Sites/nz2028/
cd ~/Sites/nz2028 && git add -A && git commit -m "обновил программу" && git push
```

Через минуту-две GitHub Pages пересоберёт страницу.
